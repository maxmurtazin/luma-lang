**Draft 001 · Proposed, unimplemented.**

Proposed contracts for map, sum, repeat, print and parallel are bounded in Draft 001. filter, reduce, find, conversions, String and File APIs remain planned. No standard library is implemented.

~~~text
result = [1, 2, 3] -> sum
~~~

See [the formal specification]({{< relref "specification" >}}) and [conformance matrix]({{< relref "conformance" >}}) for scope, open decisions and expected behavior.
