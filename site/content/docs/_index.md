Luma is in the design stage. These pages describe an intended language, not a released implementation or a complete specification.

## How to read this site

| Label | Meaning |
| --- | --- |
| Design decision | A direction chosen for the language; still unimplemented. |
| Proposed syntax | An illustrative spelling under discussion; not executable. |
| Open question | Semantics or spelling that have not been settled. |
| Roadmap | Future work with no delivery date or availability promise. |

Start with [Getting started]({{< relref "getting-started" >}}), use the [syntax draft]({{< relref "syntax" >}}) for a compact overview, and consult [Language design]({{< relref "language-design" >}}) for the decision boundary.

All code fences labeled `text` intentionally show design sketches. They are not tested Luma programs. The Hugo documentation site is the only working software delivered here.
