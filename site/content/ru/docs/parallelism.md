---
title: "Ограничения parallel"
weight: 10
---

parallel принимает до 256 элементов и запускает до восьми системных потоков для фиксированных непрерывных частей входа. Каждый элемент получает отдельную копию состояния интерпретатора и бюджет 100 000 выражений. Состояние и вывод не сливаются; результаты сохраняют порядок входа. Для пустого входа потоки не запускаются. Копирование может стоить дороже работы; ускорение не гарантируется.

Проверка запрещает захваты, ввод-вывод, косвенные вызовы, библиотечные операции высшего порядка и вложенные parallel в callback-функциях, включая транзитивные эффекты. Локальная мутация массива по значению допустима. Обычная функция может вызывать parallel. Перед возвратом все потоки завершаются. Часть входа останавливается при первой ошибке; остальные заканчивают ограниченную работу. Выбирается ошибка с наименьшим индексом. Паника становится ошибкой выполнения. API отмены и принудительного прерывания отсутствует; лимиты проверяются при вычислении. Ошибка импортированной worker-функции привязывается к файлу окружающего вызова.
