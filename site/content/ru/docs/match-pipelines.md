title: "Match и конвейеры"
weight: 8
---

x -> f(a) означает f(x, a). Вход вычисляется до явных аргументов, этапы выполняются последовательно. Запись f без скобок вызывает функцию только с входом. match проверяет литералы и сравнения по порядку, вычисляет только первое подходящее выражение и требует завершающий *. Типы результатов должны совпадать. Сравнения порядка требуют Number; литералы допускают Number, String и Bool.

~~~text
fn add(x, y)
    return x + y
end
value = 4 -> add(2)
print(match value
    > 5: "large"
    *: "small"
end)
~~~
