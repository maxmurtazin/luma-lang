Все перечисленные вызовы исполняются в 0.1.3. Конвейер вставляет первый аргумент; локальные объявления могут затенять встроенные имена.

| Вызов | Контракт |
| --- | --- |
| print(value) | Печать скаляра или вложенных массивов скаляров с переводом строки; результат Unit |
| map(array, f) | Унарный callback, порядок входа, однородный результат |
| filter(array, predicate) | Унарный предикат Bool, сохранение порядка |
| reduce(array, initial, f) | Левая свёртка f(аккумулятор, элемент); пустой вход возвращает initial |
| sum(array) | Последовательное сложение Number от положительного нуля |
| repeat(seed, step, done) | Проверка done перед шагом; первое подходящее состояние |
| parallel(array, f) | Синхронное изолированное CPU-отображение с порядком входа |

Callback-функции мономорфны; тип аккумулятора reduce может отличаться от типа элемента. sum не перегруппировывает арифметику и отклоняет неконечный результат. Последовательные callback-функции могут печатать; ошибка останавливает операцию и отбрасывает весь буфер вывода.

repeat допускает до 10 000 переходов и финальную проверку предиката; истинный начальный предикат исключает вызов шага. Общий бюджет 100 000 выражений и глубина 32 могут закончиться раньше. Сходимость не гарантируется.


~~~text
fn square(x)
return x*x
end
fn even(x)
return x%2==0
end
fn add(a,b)
return a+b
end
fn step(x)
return x+1
end
fn done(x)
return x>=5
end
a=[1,2,3,4] -> map(square) -> filter(even)
print(a[0])
print(a[1])
print(a -> reduce(10,add))
print([1,2,3,4] -> parallel(square) -> sum)
print(0 -> repeat(step,done))
~~~

**Ожидаемый вывод:**

~~~text
4
16
30
30
5
~~~

Массивы выводятся как `[a, b]`; строки внутри массивов заключены в кавычки с экранированием JSON. Отдельные строки печатаются без кавычек. Функции, объекты и Unit печатать нельзя.
