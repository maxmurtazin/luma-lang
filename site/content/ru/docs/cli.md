title: "CLI и выполнение"

Команды: luma version (или --version); luma run main.luma; luma check main.luma; luma check --syntax-only main.luma; luma check --graph graph.json main.luma. Порядок параметров обязателен. check без графа принимает несколько файлов; граф требует одну точку входа и несовместим с syntax-only.

run проверяет весь граф импортов и исполняет сохранённое AST. check не исполняет код; успешная проверка не исключает ошибок выполнения. Аргументы вычисляются слева направо. Вывод буферизуется и появляется только при успехе. Потокового вывода и интерактивного ввода нет. Лимиты — 100 000 выражений и глубина вызовов 32.

Коды выхода: 0 — успех; 1 — ошибка исходника/импорта/статической проверки; 2 — неверная команда; 3 — ошибка выполнения. Семантические ошибки и ошибки выполнения содержат файл и полуоткрытый диапазон байтов UTF-8; syntax-only использует строку/столбец. E_DIV_ZERO — деление/остаток на ноль, E_INDEX — неверный индекс, E_RUNTIME — лимиты или неконечные числа.
