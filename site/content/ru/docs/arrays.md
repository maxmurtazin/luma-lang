title: "Массивы"
weight: 5
---

Массивы однородны, индексация начинается с нуля; вложенные массивы поддерживаются. Копии и аргументы передаются рекурсивно по значению. Запись по индексу требует локального имени. Индекс должен быть целым неотрицательным Number в пределах массива; отрицательные, дробные и выходящие за границы индексы дают ошибку выполнения. Пустому массиву нужен контекст типа. append, length, срезы и общий API коллекций отсутствуют.

~~~text
a = [[1, 2]]
b = a
b[0][1] = 9
print(a[0][1])
print(b[0][1])
~~~

**Ожидаемый вывод:**

~~~text
2
9
~~~


~~~text
print([[1, 2], [3, 4]])
print(["hello", "world"])
~~~

**Ожидаемый вывод:**

~~~text
[[1, 2], [3, 4]]
["hello", "world"]
~~~
