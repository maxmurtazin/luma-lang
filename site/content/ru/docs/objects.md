---
title: "Объекты"
weight: 6
---

Объект — именованная структурная область с полями и методами. Методы читают соседние поля лексически. Доступ выполняется через имя, например Building.volume(120). Не поддерживаются неявный получатель, экземпляры, конструкторы, наследование, пространства имён как значения и произвольная запись в поля.

~~~text
object Building
    height = 25
    fn volume(area)
        return area * height
    end
end
print(Building.volume(120))
~~~

**Ожидаемый вывод:**

~~~text
3000
~~~
