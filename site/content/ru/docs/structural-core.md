title: "Структурное ядро S0/S1"

Luma предоставляет **типизированный семантический снимок только для чтения** — основу будущей Studio и адаптеров. Используется существующий checker; программа не выполняется.

Команда **luma ir main.luma** выводит JSON с версией схемы в стандартный поток вывода. Коды завершения: 0 — корректный снимок, 1 — ошибка исходника, импорта или семантики, 2 — неверные аргументы. При ошибке экспорт содержит диагностику и исходные файлы, но не содержит пригодного для использования типизированного графа.

Экспорт включает структурированные типы выражений и функций, разрешённые ссылки, связи модулей, байтовые диапазоны исходника, семантические ID, зависимости и консервативные сведения об эффектах. Идентичность файла отделена от точного содержимого. ID сохраняются при изменении комментариев, пробелов и независимых именованных объявлений; переименование, перенос и изменение позиций аргументов или ветвей могут менять ID. Это не API редактирования или исполнения сериализованной программы.

Rust API: **luma::structural::analyze(path)**. Проверяйте schemaVersion == 1 и valid перед использованием узлов. Контракт: [JSON Schema](https://github.com/maxmurtazin/luma-lang/blob/main/schema/structural-v1.json), [описание S1](https://github.com/maxmurtazin/luma-lang/blob/main/docs/structural-core-s1.md) и [аудит S0](https://github.com/maxmurtazin/luma-lang/blob/main/docs/structural-core-s0.md).

Эффекты отражают знания ограниченного checker, но не доказывают завершение или отсутствие ошибок исполнения. CAD, интеграция Living IR, структурное редактирование и Studio пока не реализованы. Команды check/run, Graph Explorer и текущий VSIX сохраняются. Новая команда доступна при сборке текущих исходников; опубликованный установщик 0.1.3 не изменён.
