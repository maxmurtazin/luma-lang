---
title: "Graph Explorer в VS Code"
weight: 12
---

Установите комплектный VSIX в VS Code 1.90+ и подтвердите доверие рабочей области для выполнения. Сохраните локальный .luma и вызовите Luma: Check File, Luma: Run File или Luma: Open Graph Explorer. Ошибки выводятся в Problems, результат — в канал Luma. luma.executablePath принимает только путь к исполняемому файлу без аргументов оболочки.

Graph Explorer показывает направленные семантические связи. Доступны фильтры по тексту/функциям/объектам/модулям, масштабирование, перемещение и переход по нажатию на узел или строку списка. У встроенных функций нет позиции исходника. Сохранение обновляет выбранную точку входа через luma.debounceMs (по умолчанию 500); импорты тоже нужно сохранять. Несохранённые изменения делают граф недействительным до сохранения.

Граф CLI schemaVersion 1 содержит valid, producer, nodes и edges; связи: contains, imports, reads, resolves_to, calls, callback. Расширение преобразует байтовые диапазоны UTF-8 в позиции UTF-16. При ошибках возможен частичный граф: проверяйте valid. Идентификаторы на основе диапазонов меняются после правок; крупные графы могут работать медленно. Отладчика и визуального редактирования нет. Лимиты процесса — 30 секунд и 16 МиБ вывода. Модульные тесты не запускают интерактивный Extension Host.
