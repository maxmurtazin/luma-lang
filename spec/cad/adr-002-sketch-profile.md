# ADR 002 · Sketch и граница профиля

Решение принято для CAD-0. Преобразователи относятся к CAD-2.

[Sketch и Profile v1](../../schema/cad/sketch-profile-v1.json) используют
локальный декартов репер в SI, направленные сегменты и дуги, окружности и стабильные UUID.
Sketch хранит авторские кривые и constraints. Profile является проверенной производной от
закреплённой ревизии Sketch. Его петли содержат ссылки на source curve ID и направление обхода.
Плоское вложение и метрические допуски проверяет адаптер перед передачей в B-rep.

В Core владельцем embedded sketch является проект. `living-sketch` выполняет
проверку профиля. Автономным документом и constraints владеет `living-ir-2d`.
Переход из 2D требует точной карты IDs, явного пересчёта единиц и подтверждённого
переноса constraints. При потере constraints или topology необходим отчёт конверсии.
Доступ к исходному формату `living-sketch/research-source@1` ограничен его профилем.
До регистрации и проверки Core state embedded write недоступен.
