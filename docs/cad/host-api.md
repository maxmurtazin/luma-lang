# CAD-1 · проверка исходника через host API

Чекер принимает явно выбранный режим `recipe` или `command`. Для режима
`command` доступен профиль `units-v1`. Профиль `recipe-parameters-v1`
подключает декларации и выражения параметров. [Параметры рецепта](parameters.md) Доступны `units.m`, `units.cm`, `units.mm`, `units.inch`,
`units.rad`, `units.deg`, `units.seconds`, `units.add` и `units.subtract`.
Объекты Length, Angle и Time содержат конечное значение в SI. Сложение
и вычитание требуют одинаковой размерности.

```sh
cargo run --locked -- cad check examples/cad/units-check.json --mode recipe
cargo run --locked -- cad check examples/cad/units-check.json --mode command
```

Команда принимает SourceBundle v1. Вход ограничен 256 KiB, пакет ограничен
16 файлами, 32 KiB исходника и 2048 токенами. SHA-256 пакета вычисляется по
LCAN/1 и учитывает точные UTF-8 байты, включая комментарии и переводы строк.
Для сборки своего пакета из Rust используется
`luma_cad_contract::source_digest(entry, files)`. Пример синтетический и
содержит ровно один файл. [Проверяемый пакет](../../examples/cad/units-check.json)

На stdout выводится один JSON envelope `luma.cad.host-check/1`. Код 0
означает успех, 2 — ошибку использования, ввода или версии, 3 — ошибку
проверки, 5 — несовпадение digest, 6 — превышение лимита. Проверка статическая.
Файлы, импортированные через `use`, берутся из пакета. Совпадение зарезервированного
host-модуля и sibling-файла выдаёт `ModuleNameCollision`.

## Встраиваемая оценка

`luma::host::check_with_host` связывает исходник, режим и точный набор
дескрипторов. `CheckedProgram::execute` сверяет реестр диспетчера с реестром
проверки до первого вызова. `luma::host::run_with_host` объединяет оба шага.
Дескриптор проверяет аргументы и результат. Конечный набор допустимых типов
переменной сигнатуры специализируется заново на каждом прямом вызове.
Пользовательские функции по-прежнему мономорфны.

Выход содержит типизированные скалярные и opaque bindings входного модуля,
записи effectful host calls с позициями исходника, диагностический текст
и число использованных шагов. Worker для `parallel` получает снимок языка
и вызывает только операции с эффектом Pure. Диспетчер — доверенный Rust API
для вычислений и записи предложений. Это встраиваемый профиль с лимитом
шагов и исходника. Изоляция внешних провайдеров и их сроки относятся к
исполнению CAD-плана.

Работа с моделью потребует планирования геометрии, командных bindings,
адаптера Core и CAS. До подключения адаптера операции
в этих модулях отклоняются как `UnsupportedCapability`. [Границы CAD-0](README.md)
