# Кандидат выпуска CAD

Манифест кандидата привязывает исходники, lock, реестр, схемы и файлы
приёмки CAD‑0…CAD‑6 к одному Git-коммиту. Версия языка берётся из
`Cargo.toml` выбранного коммита. Версии CAD API записаны для отдельных
операций. Версии структурной схемы, wire, дескрипторов и форматов
хранения имеют отдельные поля.

Генератор читает файлы из выбранного дерева Git и сверяет контрольные
суммы контрактных входов с lock. Повтор на том же дереве даёт тот же
манифест. Проверка принимает ровно состав и значения этого манифеста.
Дайджесты доказательств относятся к файлам в исходном дереве.

`recorded_target_verification` сохраняет результаты из реестра, а
`candidate_runtime` показывает проверку исполняемого кандидата на
каждом целевом стенде. При создании манифеста последний статус
равен `not_run`. Для выпуска дополнительно требуются проверка
исполняемых артефактов и новые результаты на заявленных стендах.
[Платформы и выпуск](../../spec/cad/Luma-CAD-Development-Specification-v1.0-RU.md)

## Воспроизведение

В окружении валидатора CAD с Python 3.12 укажите один и тот же Git ref
для создания и проверки. Для воспроизведения позже возьмите полный
SHA из поля `commit`.

```sh
REV=$(git rev-parse HEAD)
python -B tools/cad/validate.py
python -B tools/cad/release-manifest.py --revision "$REV" > cad-candidate.json
python -B tools/cad/release-manifest.py --revision "$REV" --verify cad-candidate.json
python -B tools/cad/test-release-manifest.py
```
