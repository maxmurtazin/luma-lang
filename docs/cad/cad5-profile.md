# CAD‑5 · Сборки, Elements и ассоциативный чертёж

Профиль проверен на Linux x86‑64 с Rust 1.100.0. Нативная сборка и
её история хранятся в Core. Каталог, переносимые архивы и SQLite workspace
Elements используют собственное хранилище. При выпуске чертежа Core
проверяет ревизию источника, а файл публикуется отдельной операцией.
[Ревизии провайдеров](../../luma-cad.lock.json)

| Проверка | Подтверждение |
| --- | --- |
| AT‑020 | Рецепт сохраняет ранее принятый выход, если на него ссылается сборка. [Тест Core](../../integrations/living-ir-core/project.rs) |
| AT‑030, AT‑057 | Core использует одну транзакцию для зарегистрированного 2D-состояния. Автономный Elements проверяет и публикует изменения своего workspace. Попытка вызова `elements.place` в Luma отклоняется, каталог сохраняется. [Встроенный 2D](embedded-2d.md) · [Проверка каталога](../../tools/cad/test-elements-catalog.py) |
| AT‑038 | Ведомость различает детали с одинаковым ID выходной feature по документу и сохраняет координаты и пути экземпляров. [Тест сборки](../../integrations/living-ir-core/assembly_reports.rs) |
| AT‑055 | Сохранившаяся опора размера пересчитана после явного выбора новой ревизии. Отсутствующая опора и устаревшая проверка блокируют выпуск. [Тест чертежа](../../integrations/living-brep-core/cli_test.rs) |
| AT‑058 | A4/A3, листы SVG/PDF и DXF контура проверены в автономном 2D. Проекция Core-пластины выпускается с политикой `review`. [Квалификация 2D](../../tools/cad/test-standalone-2d.py) · [Выпуск чертежа Core](brep-project.md) |
| AT‑062 | Установка новой версии сохраняет разрешимость прежнего пакета, вариант и BOM. Изменение нативного источника применяется к выбранному экземпляру. [Проверка Elements](elements-catalog.md) · [Ведомость Core](core-project.md) |
| AT‑063 | Учитываются вложенные экземпляры. Раскрой доступен для поддержанных элементов Elements, неизвестная плотность отражается отдельно. Проверка AABB сообщает консервативные границы. [Контракт Elements](https://github.com/maxmurtazin/living-ir-elements/blob/13b06f7ad2885385e27b81d5ee0f118e89217cb0/docs/ADAPTER-CONTRACT.md) |

Численный профиль Core-проекции ограничен аналитической пластиной.
Производственный выпуск требует доказанной погрешности проекции,
а запись экземпляров Elements в Core требует регистрации
типизированного состояния.
