# CAD-1 · параметры рецепта

В режиме `recipe` функции `param.length`, `param.angle`, `param.scalar`,
`param.count` и `param.boolean` объявляют параметры со стабильными ключами.
`param.bounds` задаёт замкнутый диапазон числового параметра,
`param.expose` управляет доступом к override, а `param.value` читает
эффективное значение. Count принимает целые числа от 0 до 2⁵³−1.

```sh
cargo run --locked -- cad check examples/cad/plate-parameters.json --mode recipe
```

Вход содержит объявление ширины 100 мм и выражения для координат двух
отверстий. При override 120 мм координаты меняются с ±40 на ±50 мм.
Исходный default остаётся 100 мм. [Пакет исходников](../../examples/cad/plate-parameters.json)

## Подготовка из Rust

`luma::cad::prepare_parameters` принимает пакет исходников,
прежний `ParameterSnapshot` одного экземпляра и бюджет оценки.
Результат содержит новые декларации, overrides и именованные
выражения. Для подготовки override на копии снимка используется
`ParameterSnapshot::with_override`. Для пакета типизированных override-правок
`luma::cad::prepare_parameter_edits` готовит конечный снимок и один раз
пересчитывает принятый рецепт. Если новый default или override выходит
за bounds, меняется тип существующего ключа либо исчезает ключ с override,
подготовка завершается ошибкой. Входной снимок доступен для повторной подготовки.

В выражениях `param.add`, `param.subtract`, `param.scale`,
`param.divide_scalar` и `param.negate` поддержаны Length, Angle и Scalar.
Совпадающие подвыражения переиспользуются внутри графа. Каждый узел сохраняет
позицию исходника. `ParamExpr::evaluate` вычисляет граф по эффективным
значениям параметров из переданного снимка. Отдельные вызовы специализируются
по типам аргументов, включая подъём величин и ссылок в выражения.

Профиль готовит параметры в памяти. Командные bindings, авторитетное
хранилище и сборка геометрии подключаются на следующих шагах CAD-1.
